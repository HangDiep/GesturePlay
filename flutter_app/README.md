# DEAD SIGNAL Flutter 2D

Bản chính là một map Thị trấn bị phong tỏa, với atlas nhân vật/quái, phố cổ ma mị và luật sống sót 180 giây. Flutter/Dart chạy giao diện, vẽ cảnh, va chạm, đạn và luật chơi. Python nhận diện tay qua webcam.

Từ thư mục gốc dự án:

```powershell
cd D:\GesturePlay
npm run web
```

Hoặc `npm run windows`. Chi tiết tại [hướng dẫn một map](../SINGLE_MAP.md) và [README chính](../README.md).

WASD/mũi tên đi, chuột ngắm và bắn, Shift chạy, Space lướt, R thay đạn, Q đèn chớp, E bẫy, Esc tạm dừng. Màn hình nhỏ có hai cần cảm ứng. Chọn Bàn tay / Webcam trên trang chủ để dùng webcam.
