# DEAD SIGNAL Flutter 2D

Bản chính có nhân vật điều khiển được trong bốn bản đồ 2D. Flutter/Dart chạy giao diện, vẽ cảnh, va chạm, đạn và luật chơi. Python chỉ nhận diện tay qua webcam.

Từ thư mục gốc dự án:

```powershell
cd D:\GesturePlay
npm run web
```

Hoặc `npm run windows`. Chi tiết tại [hướng dẫn trò chơi](../DEAD_SIGNAL.md) và [README chính](../README.md).

WASD/mũi tên đi, chuột ngắm và bắn, Shift chạy, Space lướt, R thay đạn, Q đèn chớp, E bẫy, Esc tạm dừng. Màn hình nhỏ có cần di chuyển và nút bắn. Bật Điều khiển bằng bàn tay ở màn chọn bản đồ để dùng webcam.
